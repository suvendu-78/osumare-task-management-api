# Osumare Task Management API

## Description

A RESTful Task Management API built using
Node.js and Express.js.

## Technologies

- Node.js
- Express.js
- JavaScript
- Postman

## Features

- Create tasks
- Get all tasks
- Get task by ID
- Update tasks
- Delete tasks
- Input validation
- Error handling
- Pagination
- Sorting
- Filtering

## Installation

1. Clone the repository.
2. Run npm install.
3. Run npm start.

## API Base URL

http://localhost:8000/api/v1

## Storage

Tasks are stored in an in-memory JavaScript array.
No database is required.

## API Endpoints

POST /tasks
GET /tasks
GET /tasks/:id
PUT /tasks/:id
DELETE /tasks/:id
